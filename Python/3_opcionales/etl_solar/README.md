# ETL Solar (Opcional, Python)

Objetivo: practicar un flujo ETL completo con datos de dos plantas solares.

En este modulo se hace:
- lectura de fuentes crudas (`raw_data/`),
- limpieza y unificacion de columnas,
- creacion de variables derivadas,
- exportacion de un dataset listo para analisis (`solar_efficiency.csv`).

Archivo principal: `etl.ipynb`.
